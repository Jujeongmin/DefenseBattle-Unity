# 4단계 봇 대전 (PvP 화면) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 실행: Native (superpowers:executing-plans, 사용자 지시 2026-11-17 "물어보지 말고 끝까지"). 기록: `.superpowers/sdd/2026-11-17-bot-pvp/progress.md`. 각 Task 는 테스트 → 구현 → 컴파일·콘솔 확인 → 플레이 확인 → 커밋 → push.

**Goal:** 로비 '대전 시작' → (첫 판은 바로, 이후 상대 찾기 연출) → 3초 카운트다운 → 봇과 대전(상대 전장 미니맵·상대 카드·몹 카드 끌어 던지기·포물선·착지 경고) → 결과(트로피·보석·상자·로드)까지. 완료 기준: 봇 대전 한 판 3~4분, 승패·트로피가 서버에 반영.

**Architecture:** 봇 진행은 이미 이식된 Core `BotMatch`(헤드리스 봇 전장 + `BotPlayer` 판단)가 하고, 트로피·보상은 서버 `PvpBotStart`/`PvpBotResult` 가 정한다. 화면 쪽은 `PvpDuel`(판 연결: 플레이어 Game ↔ BotMatch 공격·스냅샷 교환, 카운트다운, 결과 보고)과 런타임에 만드는 `PvpHud`(VS 줄·몹 카드 줄), 상대 전장을 RenderTexture 로 그리는 `OppBoardView` 로 나눈다. 실시간 상대(6단계)도 같은 `IPvpOpponent` 를 구현하면 끼울 수 있게 봇 쪽을 인터페이스 뒤에 둔다.

**Tech Stack:** Unity 6000.4 2D URP, uGUI + TMP, C# Core (`noEngineReferences`), UGS Cloud Code.

**Spec:** `docs/superpowers/specs/2026-10-19-defense-battle-port-design.md` (4단계, 씬 구성안 1·2·5). 원본: `../DefenseBattle/game/src/pvp.ts`(BotSession·findMatch), `main.ts`(startPvp·showPvpResult·exitGame), `menu.ts`(startMatchmaking·launchPvp), `ui.ts`(PvP HUD·buildAttackCards·flyThrow·showThrowHint·countdown·setOpponent), `oppRender.ts`.

## Global Constraints
- Core 는 `UnityEngine` 참조 금지. 원본 숫자에는 출처 주석.
- 매 프레임 코드 할당 0 (`BattleRunner.LastFrameAlloc`), 풀링, `Update` 안 `GetComponent`/`Find` 금지.
- 화면 문구는 한국어 원문 키 `Loc.Tl` (없는 키는 `Tools/i18n_extra.json` 에 5개 언어로 추가).
- 재화·트로피는 서버 권위 (`PvpBotResult` 응답의 `Econ` 을 `EconCache.Apply`).
- 씬·프리팹 YAML 손편집 금지. PvP HUD 는 런타임 생성 (3단계 결정: 로비/페이지 UI 는 코드로 만든다), 씬 연결은 MCP.
- 사용자 결정: 첫 대전은 봇, 처음 3판은 가장 약한 봇(`BotProfile.Skill` 이미 반영), 봇 승리는 시작 5초 뒤부터 인정(서버 `BotMinMs`). 실시간 매칭은 6단계 → 지금은 원본 오프라인 경로(1.5~3.5초 찾는 연출 뒤 봇).

## Review Focus
1. 판 도중 나가기: 확인 뒤 패배 보고(트로피 감소)되고, 봇 진행·타이머가 멈춰 로비에 영향이 없어야 한다 → Task 2 플레이 확인 + `PvpDuel.Leave` 뒤 `BotMatch.Done`.
2. 서버 결과가 안 오거나 실패: 결과 화면은 6초 안에 '트로피 0' 으로라도 떠야 하고 두 번 뜨지 않는다 → Task 2 `PvpResultTests`(중복 무시) + 플레이에서 오프라인 확인.
3. 카운트다운 중 입력: 소환·던지기·영웅 패널이 막혀야 한다 → Task 3 (`PvpHud.CountingDown` 동안 버튼 비활성).
4. 첫 대전: 던지는 법 안내가 뜨고, 한 번 던질 때까지 소환이 잠긴다 (던질 카드가 없으면 풀림) → Task 5.
5. 상대 전장 스냅샷이 늦게/몰려 올 때 미니맵 몹이 튀지 않는다 → Task 1 `SnapshotTimelineTests` (늦은 스냅샷 무시, 끊긴 뒤 따라잡기).
